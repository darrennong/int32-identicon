# Roadmap / 开发任务

`0.1.1` 是协议与扫描原型的定位修复版本，不表示手机连续扫描已验收。

| 阶段 | 状态 | 已交付 | 剩余工作 |
|---|---|---|---|
| 1 协议 | 已完成 | V1、16 HEX、RS/CRC、固定向量、独立参考编码器 | 线格式变化走新版本评审 |
| 2 Rust | 已完成 | 编解码、网格、全部颜色、边界、10 万随机测试 | fuzz 与更多互操作测试 |
| 3 样例 | 已完成 | 10 PNG + 10 SVG、manifest、像素解码与 WASM 复核 | 真实拍摄样本 |
| 4 静态识别 | 原型完成 | 多色色卡弧段定位、透视采样、色卡检查、8 方向、镜像、灰色屏幕场景回归、一张手机预览截图像素验证 | 更多真实场景、反光、模糊、真实失败集 |
| 5 网页 | 原型完成 | WASM、Worker、摄像头、图片导入、三帧确认、Pages 工作流 | Safari / Chrome 真机兼容验收 |
| 6 实机 | 待开展 | 验收矩阵与模板 | 手机实测、性能、可用条件与限制 |

## 下一批任务

GitHub 跟踪：[真实图片识别 #1](https://github.com/darrennong/int32-identicon/issues/1) · [手机浏览器兼容 #2](https://github.com/darrennong/int32-identicon/issues/2) · [实机与性能 #3](https://github.com/darrennong/int32-identicon/issues/3)。

1. 用真实 iPhone / Android 手机扫描电脑和另一台手机屏幕，保留不含私人背景的授权测试裁图。
2. 根据更多失败样本改进定位。0.1.1 已修复将周围文字当成边界的问题，改为多色色卡弧段与四条长边定位；仍不保证任意复杂场景可用。显式四角 API 可区分定位与采样问题。
3. 测量色偏、过曝、PWM / 摩尔纹、模糊与反光，调整质量阈值。拒绝优先于猜测。
4. 建立真实失败集、随机图像负样本统计、fuzz、浏览器集成回归与性能分位数。
5. 验收后发布 `0.2.0` 和实测可用条件，再考虑离线缓存、打印、多图定位、可逆视觉风格扩展。

不可为了让个别图片通过而放松 CRC、跳过歧义检查或任意补画格子。协议变化须更新规范、固定向量，保留旧版本解码能力。
